# 开始前准备界面与普通道具配置

本文按界面从上至下、从左至右的顺序说明。

## 1. 返回 icon

点击左上角“◀ 返回”，回到歌曲选择界面。准备界面中的装备草稿在返回后保留；开始新游戏时清空。

## 2. 已装备弹幕区域

展示当前装备弹幕的图标和名称，同一时间装备一种弹幕。未装备时保持空白，仅在底部显示浅色“+”。初次进入准备界面不自动装备。

单击已装备弹幕查看说明，双击将其卸下。卸下后立即禁用 Link start!。

## 3. 已装备道具区

最多同时装备三种道具，也允许零道具。未使用的槽位只显示底部浅色“+”。单击已装备道具查看说明，该槽位显示亮蓝色加粗边框；双击快速卸下。同一道具不能重复占用多个槽位。

## 4. 文案介绍区

显示当前单击选中的弹幕或道具名称及说明，包括右侧未解锁的道具。未选中时为空白。每次重新打开准备界面清空文案选择，保留装备草稿。

所有弹幕及道具描述均支持 CSV 表格配置，文件为 `Assets/Configs/Spotlight/LoadoutTexts.csv`。表头固定为：

| Kind | Id | DisplayName | Description |
|---|---|---|---|
| Weapon | Normal / Spread | 弹幕显示名称 | 弹幕说明 |
| Item | ItemDefinition.Id，例如 item-1 | 道具显示名称 | 道具说明 |

在 Excel 或其他表格软件中编辑后另存为 UTF-8 CSV，然后执行 **Tools → Spotlight → 从CSV导入装备文案**。逗号、换行和双引号按标准 CSV 转义。整表校验完成后才写入；未知 Id、重复行或错误表头会被拒绝，不会部分覆盖资产。

新增道具时创建 ItemDefinition，将其加入 SystemConfig.Items，再在 CSV 中增加对应 Id。显示顺序沿用 SystemConfig.Items 的数组顺序。

## 5. 弹幕类型区

目前显示普通弹幕、散射弹幕。单击仅查看文案；双击已解锁且配置有效的弹幕，装备到左侧弹幕栏。装备其他类型时替换原有类型。

PlayerWeaponDefinition.Unlocked 控制解锁，默认两种均解锁。未解锁或配置无效的类型置灰，仍可查看说明，无法装备。Homing 类型尚未加入本界面。

## 6. 道具类型区

初始六种道具，按三列排列。已获得道具常亮；未获得道具置灰。所有道具均支持单击查看说明；双击已获得且有配置效果的道具快速装备，槽位满时提示先卸下。双击已经装备的右侧道具不会重复装备或卸下，卸下通过左侧槽位完成。

列表使用纵向 ScrollRect、Viewport 裁切和 ContentSizeFitter，增加道具后自动增高，可以通过滚轮或拖动上下浏览。

| 稳定 Id | 当前名称 | 效果 |
|---|---|---|
| item-1 | 血量回复道具 | 主动使用，恢复 2 点生命值 |
| item-2 | 短时弹幕爆发道具 | 主动使用，5 秒内提高射速和每轮弹幕数量 |
| item-3 | 星光护符 | 占位 |
| item-4 | 演出耳机 | 占位 |
| item-5 | 幸运手环 | 占位 |
| item-6 | 聚光镜片 | 占位 |

前两个道具沿用原有 item-1 / item-2 的存档 Id，保留已有获取记录。其余道具沿用现有 DebugLogItemEffect 占位效果。

## 7. Link start! 按键

未装备弹幕时置灰且不能点击；装备有效弹幕后常亮，允许零道具开局。点击后沿用现有歌曲、难度和装备校验流程，进入加载界面，再进入本局战斗。界面返回以及重新选歌均沿用已有场景流程。

## 8. 普通道具效果与限制

普通道具单局可用数量为 `min(库存数量, MaxHeldPerRun, UsesPerRun)`。成功使用后扣除一次本局数量，并进入 CooldownTicks 冷却；无法生效时不扣次数。延续项目现有存档规则，局内使用不扣永久获取数量，重试重建道具状态并恢复本局次数。若将来改为永久消耗品，需要另行调整存档结算规则。

| 参数 | 血量回复道具 | 短时弹幕爆发道具 |
|---|---|---|
| 效果资产 | Run/HealEffect.asset | Run/BurstEffect.asset |
| 核心效果 | 恢复 2 点生命值，不超过血量上限 | 持续 300 Tick，即 5 秒 |
| 默认携带上限（可调整） | 3 | 3 |
| 默认每局使用上限（可调整） | 3 | 3 |
| 默认冷却（可调整） | 60 Tick，即 1 秒 | 300 Tick，即 5 秒 |
| 默认爆发倍率（可调整） | — | 射速 ×2，每轮弹幕数量 ×3 |

回血不复活已倒下的角色，满血时不消耗次数。爆发支持普通与散射弹幕，使用 BuffManager 在战斗 Tick 边界生效，到期后恢复基础射速和发射数量，暂停不消耗时间。弹幕数量限制为每轮 1–64 枚，射速沿用现有每秒最多 60 轮限制；基础武器资产不被运行时修改。

## 9. 接入与验证

现有 Prefab 已通过 Unity 编辑器 API 更新。需要重新接入时执行 **Tools → Spotlight → 更新开始前准备界面**；该工具会重置前两个道具的默认参数，日常只改文案应使用 CSV 导入菜单。

- **Tools → Spotlight → 验证准备界面与普通道具**：验证回血、携带数量、爆发与到期恢复、表格校验、Prefab 滚动结构，输出 `Logs/SpotlightLoadoutValidation.txt`。
- PlayMode 测试 `LoadoutPreviewDoubleClickSlotsAndStartGate`：验证空白初始状态、锁定道具说明、单/双击、三个槽位、高亮、弹幕卸下禁用开始、扩展列表滚动与返回。
- 既有 SystemFlowTests 继续验证歌曲、加载、道具动作接受、结算、重试与存档流程。
