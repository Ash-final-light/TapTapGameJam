# 开始前准备界面与普通道具配置

本文按界面从上至下、从左至右的顺序说明。

## 1. 返回 icon

点击左上角“◀ 返回”，回到歌曲选择界面。准备界面中的装备草稿在返回后保留；开始新游戏时清空。

## 2. 已装备弹幕区域

展示当前装备弹幕的图标和名称，同一时间装备一种弹幕。未装备时保持空白，仅在底部显示浅色“+”。初次进入准备界面不自动装备。

单击已装备弹幕查看说明，双击将其卸下。卸下后立即禁用 Link start!。

## 3. 已装备道具区

最多同时装备三种道具，也允许零道具。未使用的槽位只显示底部浅色“+”。单击已装备道具查看说明，该槽位显示亮蓝色加粗边框；双击快速卸下。同一道具不能重复占用多个槽位。

## 4. 文案介绍区

显示当前单击选中的弹幕或道具名称及说明，包括右侧未解锁的道具。未选中时为空白。每次重新打开准备界面清空文案选择，保留装备草稿。

所有弹幕及道具描述均支持 CSV 表格配置，文件为 `Assets/Configs/Spotlight/LoadoutTexts.csv`。表头固定为：

| Kind | Id | DisplayName | Description |
|---|---|---|---|
| Weapon | Normal / Spread | 弹幕显示名称 | 弹幕说明 |
| Item | ItemDefinition.Id，例如 item-1 | 道具显示名称 | 道具说明 |

在 Excel 或其他表格软件中编辑后另存为 UTF-8 CSV，然后执行 **Tools → Spotlight → 从CSV导入装备文案**。逗号、换行和双引号按标准 CSV 转义。整表校验完成后才写入；未知 Id、重复行或错误表头会被拒绝，不会部分覆盖资产。

新增道具时创建 ItemDefinition，将其加入 SystemConfig.Items，再在 CSV 中增加对应 Id。显示顺序沿用 SystemConfig.Items 的数组顺序。

## 5. 弹幕类型区

目前显示普通弹幕、散射弹幕。单击仅查看文案；双击已解锁且配置有效的弹幕，装备到左侧弹幕栏。装备其他类型时替换原有类型。

PlayerWeaponDefinition.Unlocked 控制解锁，默认两种均解锁。未解锁或配置无效的类型置灰，仍可查看说明，无法装备。Homing 类型尚未加入本界面。

## 6. 道具类型区

当前保留两种主动道具，按三列排列。已获得道具常亮；未获得道具置灰。所有道具均支持单击查看说明；双击已获得且效果配置有效的道具快速装备，槽位满时提示先卸下。双击已经装备的右侧道具不会重复装备或卸下，卸下通过左侧槽位完成。

列表使用纵向 ScrollRect、Viewport 裁切和 ContentSizeFitter，增加道具后自动增高，可以通过滚轮或拖动上下浏览。

| 稳定 Id | 当前名称 | 效果 |
|---|---|---|
| item-1 | 血量回复道具 | 主动使用，恢复 2 点生命值 |
| item-2 | 短时弹幕爆发道具 | 主动使用，5 秒内提高射速和每轮弹幕数量 |

两个道具沿用原有 item-1 / item-2 的存档 Id，保留已有获取记录。原四种占位道具已从目录、掉落表、CSV 和资源中移除，旧存档中的历史获取记录不会显示或参与装备，也不会影响成绩读取。无需删除玩家存档。

## 7. Link start! 按键

未装备弹幕时置灰且不能点击；装备有效弹幕后常亮，允许零道具开局。点击后沿用现有歌曲、难度和装备校验流程，进入加载界面，再进入本局战斗。界面返回以及重新选歌均沿用已有场景流程。

## 8. 普通道具效果与限制

普通道具单局可用数量为 `min(库存数量, MaxHeldPerRun, UsesPerRun)`。成功使用后扣除一次本局数量，并进入 CooldownTicks 冷却；无法生效时不扣次数。延续项目现有存档规则，局内使用不扣永久获取数量，重试重建道具状态并恢复本局次数。若将来改为永久消耗品，需要另行调整存档结算规则。

| 参数 | 血量回复道具 | 短时弹幕爆发道具 |
|---|---|---|
| 效果资产 | Run/HealEffect.asset | Run/BurstEffect.asset |
| 核心效果 | 恢复 2 点生命值，不超过血量上限 | 持续 300 Tick，即 5 秒 |
| 默认携带上限（可调整） | 3 | 3 |
| 默认每局使用上限（可调整） | 3 | 3 |
| 默认冷却（可调整） | 60 Tick，即 1 秒 | 300 Tick，即 5 秒 |
| 默认爆发倍率（可调整） | — | 射速 ×2，每轮弹幕数量 ×3 |

回血不复活已倒下的角色，满血时不消耗次数。爆发支持普通与散射弹幕，使用 BuffManager 在战斗 Tick 边界生效，到期后恢复基础射速和发射数量，暂停不消耗时间。弹幕数量限制为每轮 1–64 枚，射速沿用现有每秒最多 60 轮限制；基础武器资产不被运行时修改。

### 局内输入与结算顺序

- 按住 Tab，通过数字键或点击槽位选择道具；按 R 使用选中的道具。按下 R 时立即记录道具 Id，之后切换选中项不会改变已经提交的请求。
- 两种主动道具均为即时效果。角色存活时，可在移动、跳跃、飞行、冲刺、技能和受击动作期间使用；不打断、不重启动作，不占用技能或跳跃的输入名额，不在动作缓冲中等待。
- 每个战斗 Tick 最多处理一次道具使用。固定顺序为：道具校验与生效 → 增益到期处理及属性读取 → 玩家动作、移动与发射 → 碰撞伤害。回血可以在同一 Tick 的致命碰撞前保命；已经死亡的角色不能复活。爆发影响使用当 Tick 的普通武器发射。
- 未装备、次数用完、冷却中、生命已满或效果配置无效时，拒绝请求并提示原因，不扣次数，也不产生新的冷却。拒绝的请求不会延迟到以后自动执行。
- 暂停清空尚未执行的输入，暂停期间不能提交使用请求；继续游戏不会补执行暂停前残留的 R。

### HUD 状态

- 当前道具卡展示道具名及“可使用／生命已满／冷却剩余／效果剩余”等状态。
- 使用图标和选择槽位显示冷却遮罩与秒数，不可用图标变灰；回血图标为绿色、爆发图标为橙色，可通过 ItemDefinition.IconColor 调整。成功或失败均在道具卡下方显示反馈，不遮挡顶部节拍面板。
- 选择栏保留本局装备的固定槽位，次数用完显示“已用完”并禁用选择，不会导致数字快捷键重新编号。爆发最后一次用完后，其效果剩余时间仍可在原槽位查看。
- 用完当前道具后，自动选择仍有次数的下一种道具；全部用完后显示“本局道具已用完”。

### 后续增加道具

创建 ItemDefinition 和实际 ItemEffect，将道具加入 SystemConfig.Items，再配置 Drops 及 CSV 文案。ItemEffect.Validate 检查静态配置，UnavailableReason 检查当前使用条件，Apply 仅在实际生效时返回 true；持续效果通过 RemainingTicks 提供剩余时间。次数、冷却、请求身份和 HUD 反馈统一由现有流程处理，不再加入只打印日志的正式道具。

## 9. 接入与验证

现有 Prefab 已通过 Unity 编辑器 API 更新。**Tools → Spotlight → 更新道具目录与使用反馈** 可重复清理占位资源并补齐现有 HUD，不重置两个道具已配置的数值。旧版歌曲装备生成工具也已改为生成真实回血和爆发道具，不会再生成占位道具。需要重新接入准备界面时执行 **Tools → Spotlight → 更新开始前准备界面**；该工具会重置前两个道具的默认参数，日常只改文案应使用 CSV 导入菜单。

- **Tools → Spotlight → 验证道具使用流程**：核对目录与掉落、满血及死亡拒绝、冷却与次数、无效效果、普通／散射爆发、同 Tick 生效、输入身份、动作连续性、回血先于碰撞、固定槽位，以及重试和永久库存规则，输出 `Logs/ItemUsageValidation.txt`。

- 目录与状态更新后，应通过真实战斗场景检查选中项、次数和冷却显示，并在原有歌曲加载、结算和重试流程中验证。
