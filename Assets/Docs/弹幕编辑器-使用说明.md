# 弹幕编辑器：简化版使用说明

更新日期：2026-10-11。编辑器显示中文；默认按秒编辑，内部仍采用每秒 60 帧的固定模拟。

## 打开与快速制作

1. 在 Unity 菜单打开 `工具 > 弹幕 > 弹幕编辑器`，或双击攻击资产。
2. 点击“新建”，再点击“＋添加弹幕”，选择一种内置花样。
3. 内置花样自带发射点，添加后可以直接播放。普通花样默认间隔 0.5 秒；子母弹默认一次发射、一次更晚的分裂。
4. 在右侧“片段”页调整颗数、弹速和花样相关参数。
5. 在“发射时间”选择发射一次或连续发射，设置时间、间隔和次数，然后点击“应用发射时间”。
6. 点击“播放”查看效果，点击“保存”保存为攻击资产。

“添加空白片段”不会生成发射点，适合从零编排。“我的预设”显示项目中的发射预设；拖入保存的预设会独立复制其时间点。

## 八种内置花样

| 花样 | 用途与主要参数 |
| --- | --- |
| 直线发射 | 颗数、方向、弹速；多个时间点组成连射 |
| 瞄准扇形 | 发射时瞄准玩家；颗数、瞄准偏移、扇形角度、弹速 |
| 固定扇形 | 颗数、中心方向、扇形角度、弹速 |
| 圆环扩散 | 每圈颗数、起始方向、弹速 |
| 旋转扫射 | 发射方向数、旋转速度、弹速 |
| 横排墙弹 | 颗数、线阵起点／终点、方向、弹速 |
| 交错圆环 | 每轮颗数、相邻轮次交错角度、弹速 |
| 子母弹 | 母弹颗数、母弹速度、发射／分裂时间、分裂子弹模板／颗数／速度 |

瞄准只发生在发射时。旋转扫射改变发射方向，已出生的子弹继续沿初始方向直线移动。子母弹只有一个发射点、一个分裂点，分裂必须晚于发射；子弹不继续分裂。

已取消随机发射角度、速度层数和每层速度差，每段弹幕只有一个基础弹速。母弹和分裂后子弹可以分别设置速度。原“花瓣／交错环”改为单一弹速的“交错圆环”。

## 右侧面板

- **片段**：名称、开始时间、长度、禁用、发射位置、花样参数、发射时间、子弹外观和寿命。只展示当前花样相关的常用参数。
- **攻击设置**：攻击总时长、场地大小、结束清弹、预警／清弹事件；随机种子和同屏子弹上限折叠在“更多攻击设置”。
- **预览设置**：测试玩家位置、玩家配置、首领图片、碰撞开关、判定圈。

引用预设时，发射参数先只读显示；点击“调整此片段的发射参数”会复制为局部参数。子弹模板同样通过“调整此片段的子弹参数”复制到当前片段。修改这些局部配置不会修改模板资产。

“子弹外观与寿命”包含图片、颜色、显示大小、碰撞判定半径和存活时间。显示大小是世界单位下图片的最长边，判定半径独立于外观尺寸。

“更多发射设置”保留形状、瞄准、出生偏移、发射器移动、随机区域出生和玩家保护距离。随机出生位置与已取消的随机发射角度是不同功能。所有有效弹幕伤害固定为 1，子弹有效命中一次后消失；不再提供伤害值、伤害来源、伤害配置编号、可命中次数或目标状态效果编号。子母弹的交互类型、接触伤害开关及膨胀配置集中在“能量球设置”。

## 发射时间

- **发射一次**：设置片段开始后多少秒发射，然后点击应用。
- **连续发射**：设置首次发射、间隔和次数。最后一次发射必须早于片段结束。
- **自定义时间**：手动调整为不等间隔后显示该模式；展开“逐次调整发射时间”编辑各个点。

应用发射时间是明确的替换操作，替换当前片段已有时间点，支持撤销／重做。底层仍保存独立关键帧，没有第二份重复的发射计划。

子母弹直接显示发射和分裂时间。切换花样后如果旧时间点不符合子母弹约束，可点击“设置一次发射＋一次分裂”重建；该操作同样替换已有点并支持撤销。

右键片段条添加发射点或分裂点。点击标记选择，拖动修改时间，右键复制到播放头或删除。右侧列表支持逐项删除。删除点后连续按 Delete 不会转而删除整段；重新点击片段空白处，再按 Delete 才删除片段。

## 时间轴和播放

- 拖动时间轴上方分隔条：上下调整时间轴高度，上方预览同步缩放。
- 双击分隔条：恢复默认高度，默认约占窗口高度的三分之一。
- 布局会记住上次调整的比例，并限制最小时间轴高度和预览空间。
- 拖动片段中部：调整开始时间；拖动左右边缘：调整片段范围。
- 调整片段长度不会缩放关键帧时间、弹速或单弹寿命。超出范围的点保留并显示错误，不静默删除。
- 点击时间轴空白／刻度：跳转到对应时间；滚动和缩放用于查看长攻击和多轨道。
- 底部提供回到开头、前后单帧、播放／暂停、循环、倍速和“显示帧”。默认用秒，输入会吸附到整数帧。
- 快捷键：空格播放／暂停，左右方向键前后单帧，Delete 删除选中点／片段，Ctrl+D 复制到播放头。编辑文本时不触发这些快捷键。
- “禁用此片段”停止该片段执行；“仅预览此段”只模拟当前片段；“恢复全部”恢复所有片段。

片段结束后停止继续发射，已发出的子弹根据自身寿命继续存在。活动区间为开始帧到结束帧之前，不在结束帧发射。第 0 帧表示尚未执行第一次模拟；前进一步执行第 0 帧的发射。

## 音乐辅助

无音乐时，顶栏只提供“＋添加音乐”。添加后显示音乐选择、解析、同步试听和节拍吸附。解析前需要先保存攻击资产。

导入音乐后，音乐工具栏下方提供一行“手动 BPM”和“首拍偏移（秒）”。输入 BPM 后自动在下方时间轴生成黄色“BPM 节拍”点，无需先解析音乐。例如 120 BPM 每 0.5 秒一拍。首拍偏移表示第一拍在音乐文件中的位置，可用于对齐前奏；整条轨道还会叠加“音乐开始偏移”。

BPM 支持小数，范围 1–1000；输入 0 或点击“清除节拍”关闭手动节拍。节拍生成到音乐结束之前，不改变已有弹幕时间点。启用“吸附节拍”后优先吸附手动 BPM 网格；关闭手动节拍后继续使用原有音乐解析候选点。BPM 和首拍偏移随攻击资产保存，支持撤销／重做；换入另一首音乐时清空旧歌曲的手动设置。

时间轴默认只显示一条音乐波形，候选点叠加在同一行。右侧“攻击设置 > 音乐高级设置”可展开三频段轨道、选择参与吸附的频段，并配置解析参数和音乐偏移。候选点是辅助提示，已有发射点不会被自动重排。

同步音乐播放时固定正常速度。音乐试听接口不可用时会给出中文提示。

## 保存与运行

“保存”为当前攻击保存资产；“更多 > 另存为”保存副本。“保存为预设”保存当前片段的发射参数、长度和时间点；局部子弹配置会保存为预设子资产。

“更多”中还提供内存示例、创建八类示例资产和运行模拟验证。清理旧版字段不会重建用户已有攻击或修改其编排。

运行时沿用 `DanmakuSequencePlayer`。编辑器预览使用独立场景和同一模拟逻辑，不把预览对象放入实际关卡；预览跳转不会发布真实命中回调。场景接入见[真实玩家接入](真实玩家-移动与判定接入.md)。

实战 Boss 保留显示位置、外观与弹幕发射，不再有血量、扣血、死亡或受击碰撞，玩家子弹穿过 Boss。能量球生命为 1，玩家子弹击碎一个能量球后回收，不穿透多个球。玩家的生命、无敌时间及其他移动／射速／子弹速度增益继续生效，伤害增益已取消。

有音乐的关卡以音乐实际长度加开始偏移作为结束时间；弹幕时间轴较短时，歌曲继续播放至结束，时间轴较长时则在歌曲结束处停止。没有音乐时使用弹幕时间轴结束时间。歌曲结束和角色倒下都停止战斗、关闭战斗输入，并进入同一个歌曲结算页面，分别显示“歌曲完成”和“角色倒下，歌曲结束”，结算统计、存档及奖励只执行一次。直接运行已登记的 Gameplay 场景也会匹配歌曲配置并进入结算。

## 旧资产与验证

首次导入简化版时，编辑器通过 Unity 资产序列化清理旧随机角度、速度分层、伤害与 Boss 血量字段，保留资产标识、引用及支持的配置。也可执行 `工具 > 弹幕 > 清理旧版高级与伤害配置数据`。

菜单 `工具 > 弹幕 > 验证简化版本` 检查模拟、编辑操作、默认发射点、单一弹速、发射时间替换／撤销、子母弹末尾边界、能量球和音乐解析／传输。报告写入 `Logs/DanmakuSimpleValidation.txt`、`Logs/DanmakuValidation.txt`、`Logs/EnergyOrbValidation.txt` 和 `Logs/MusicAnalysisValidation.txt`。

菜单 `工具 > 弹幕 > 验证固定伤害与歌曲结算` 还会检查固定伤害、单次命中回收、Boss 穿透、歌曲结束边界、玩家倒下，以及真实结算页面与存档去重。报告见 `Logs/BattleRulesValidation.txt`、`Logs/BattleResultFlowValidation.txt` 和 `Logs/BattleValidation.txt`。旧版高级与伤害字段会在导入后自动清理，也可以通过 `工具 > 弹幕 > 清理旧版高级与伤害配置数据` 手动清理。

现有高弹量保护、批量绘制和确定性重演保留。波浪运动、持续追踪、激光、擦弹和快照缓存不在本次简化范围内。
