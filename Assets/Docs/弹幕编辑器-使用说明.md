# Boss 弹幕编辑器：第一版使用说明

已对齐：Boss 单个攻击段／符卡，PC／手机双端，Sprite 表现，固定测试玩家。初始弹量参考约 100 颗，运行时也按更高弹量进行组织。

本轮新增音乐波形、三频段候选点、吸附及同步试听；操作见 [战斗第一阶段与音频解析-接入说明](战斗第一阶段与音频解析-接入说明.md)。

## 打开与开始编辑

1. 等待 Unity 完成脚本导入，在菜单打开 `Tools > Danmaku > Boss 弹幕编辑器`。
2. 窗口首次打开会提供内存中的 8 秒示例；点击“保存”选择 `.asset` 位置后才成为项目资产。
3. 点击“创建八类示例资产”，或执行 `Tools > Danmaku > 创建八类示例资产`，可生成 `Assets/DanmakuExamples`：八类发射预设、小圆弹、分裂母弹、示例 Sprite 和 BossExample。
4. 双击 DanmakuSequence 资产，也会打开编辑器。
5. 左侧点击内置预设，或拖到时间轴，添加发射片段。项目中的 EmissionPreset 可以从 Project 拖到时间轴，或在左侧对象框中选择。

第一版每行是一条独立发射片段／发射器，支持多行同时发射。共用发射器的嵌套轨道分组留到后续版本。

## 时间轴操作

- 点击片段：选中并显示右侧参数。
- 拖动片段中部：移动开始帧，吸附整数 Tick。
- 拖动左右边缘：调整发射窗口。缩放片段不会改变弹速或单颗弹寿命。
- 点击时间轴空白或刻度区域：回拖／跳转到对应帧。
- “复制”：复制完整局部参数，并放到当前播放头；副本获得独立 ID。
- “静音”字段：不执行该片段。“独奏”：只模拟选中片段，再点一次恢复。
- 播放／暂停、单帧前后、回到开头、倍速、循环和刻度缩放均在底部操作栏。
- 快捷键：空格播放／暂停，左右方向键单帧移动，Delete 删除片段，Ctrl+D 复制。编辑文本时不响应这些快捷键。
- Unity Undo／Redo 可撤销参数修改、片段拖动、复制与删除。

Tick 为已经完成的模拟步数。Tick 0 是执行第 0 帧发射之前的状态；前进一步会执行 `[0,1)`。片段活动区间是 `[StartTick, StartTick + DurationTicks)`，结束帧不再发射。

## 预设和单弹配置

`EmissionPreset` 负责发射，`ProjectileDefinition` 负责单颗弹，`DanmakuSequence` 负责攻击编排。

片段可以引用项目预设，或启用“本片段覆盖发射参数”。单弹模板也有对应局部覆盖，修改局部覆盖不会改动原模板。

“另存发射预设”会保存当前发射参数；若当前使用局部单弹覆盖，会把单弹配置保存为该预设的子资产，避免丢失颜色、Sprite、判定尺寸或分裂参数。

发射参数含义：

- Shape：Point 同点发射、Arc 扇形、Ring 闭合环、Segment 空间线阵。
- Count：每轮基础方向／出生点数量；SpeedLayers 会在每个方向再叠加速度层。
- IntervalTicks：轮间隔；60 Tick = 1 秒。
- DirectionDegrees：0°向右、90°向上、-90°向下。启用 AimAtPlayer 后，它是相对瞄准方向的偏移，普通自机狙用 0°。
- ArcDegrees：扇形总张角；Ring 采用 360°闭合分布，不重复两端。
- RotationDegreesPerSecond：旋转发射方向，出生后的子弹仍沿初始方向走直线。
- AlternatePhaseDegrees：奇数轮额外相位，用于交错环／花瓣组合。
- SpawnRadius：出生点沿各自发射方向偏移。
- SegmentStart／End：相对发射器的线阵端点。
- SpeedLayers／Delta：速度层数量与每层速度增量。
- RandomAngleDegrees：固定随机流中的方向扰动；同一片段 ID、种子与输入下可重演。

单弹参数含 Sprite、Color、VisualSize、HitRadius、DurationTicks、HitCount、DamageConfigId、TargetBuffIds 和分裂设置。VisualSize 是世界单位下 Sprite 的最长边；HitRadius 独立控制圆形判定。

分裂在子弹年龄达到 SplitAgeTicks 时触发。母弹回收后，子弹在下一 Tick 提交生成。SplitChild 为空时生成缩小的同色普通弹；指定子模板时使用子模板。清弹、越界和攻击重置不会触发分裂。

## 预览与事件

预览使用独立的 PreviewRenderUtility 场景，窗口关闭会释放网格、材质和临时对象。不会把预览对象放到实际关卡场景。

右侧攻击设置可调整测试玩家位置、预览玩家配置、场地尺寸、碰撞开关和 Boss Sprite。玩家半径和 Sprite 来自预览玩家配置 SO；旧资产未指定配置时沿用隐藏的旧字段。修改参数后会重演到当前帧，玩家配置半径变化也会触发预览重建。

Events 支持 Warning 和 ClearBullets：

- Warning：在指定帧开始显示预警文字，持续 DurationTicks；第一版尚未接专用预警特效。
- ClearBullets：清除指定片段所属弹及其待生成后继。ClipIndex=-1 表示清全场，其他值为从 0 开始的片段索引。
- ClearAtEnd：在攻击总时长结束后清弹。
- 循环使用硬重置，从同一随机种子重演。

Seek 会重建并重演模拟。测试命中次数仍用于显示，但不会发布实际伤害／Buff 回调。

## 放进游戏运行

选中保存的 Sequence，在 `GameObject > Danmaku > Sequence Player` 创建播放器，或给自己的对象添加 `DanmakuSequencePlayer` 并设置 Sequence。它在 XY 平面、相对对象坐标中显示。

播放器提供 Play、Pause、Resume、Seek 和 Loop，使用与编辑器相同的 60 Hz 模拟。

`OnProjectileHit` 发布 ProjectileHit，其中有逻辑子弹 ID、Tick、子弹与玩家位置、玩家判定半径、DamageConfigId、TargetBuffIds。真实 Damage／Buff 系统应在这里接入。

指定 InputSource 和 PlayerConfig 后，播放器使用实时玩家输入，并在同一个 60 Hz 时钟中先移动玩家、再更新判定与子弹。不指定 InputSource 时继续使用固定测试玩家。场景挂载、共享玩家 SO 与接口说明见[真实玩家接入](真实玩家-移动与判定接入.md)。多敌人目标尚未接入。

## 高弹量运行时策略

- 子弹没有 Unity BoxCollider2D、CircleCollider2D 或 Rigidbody2D，也没有逐颗 GameObject／Transform。
- 逻辑使用已有 FP64／LWPhysicsWorld；BulletTargetBroadphase 只生成敌弹与少量目标的候选对，不枚举敌弹之间的组合。
- LWPhysicsWorld 的稳定 ID 查询使用字典，移除、槽位复用与 Restore 会同步重建映射。
- 子弹状态对象复用；回收采用末元素交换，避免数组中间删除造成大批搬移。
- Sprite 的 vertices／uv／triangles 按资源缓存，使用可复用动态网格批量绘制。支持 Sprite 真实网格和图集 UV。
- 同一 Sprite 同一网格块可以合为一个批次。每块不超过 16,000 顶点，保持手机上可用的 16 位索引。
- 着色器位于 Resources，避免打包时因仅使用 Shader.Find 而被裁掉；使用透明纹理和顶点颜色，支持现有 URP 项目与编辑器预览。
- MaxActiveBullets 是可调整的保护上限，超限停止并报告来源片段，不静默丢弹。编辑器最大允许值为 16,384；默认 256。

仍需根据最终弹型与目标手机测量透明像素覆盖、Sprite 网格复杂度、批次数量、生成峰值与 GPU 时间。PC 的逻辑 CPU 测试不能替代手机整帧测试。

## 验证与当前范围

菜单 `Tools > Danmaku > 运行模拟验证`，或窗口“验证”，运行 Unity 原生引擎中的回归检查，输出 `Logs/DanmakuValidation.txt`。

检查包含八类预设的重演一致性、结束帧、分裂年龄、清弹、命中去重、Seek 回调隔离、序列化、物理 ID 映射恢复、候选对数量，以及 100／1,000／5,000 弹压力测试、持续发射回收和 Sprite 批绘制。首轮 12 项检查已通过，环境和测量边界见[性能与验证记录](弹幕编辑器-性能与验证.md)。

第一版支持直线运动、瞄准发射、发射方向旋转、有限子母弹和线性发射器移动。Wave／Homing、停顿转向、激光、擦弹、连续碰撞检测和快照缓存未包含在此版。

高速小弹当前使用离散圆判定，调试时应控制单 Tick 位移；需要高速弹时再接 Sweep 或双方相对运动的连续检测。
