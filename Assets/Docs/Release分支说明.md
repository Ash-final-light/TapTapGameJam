# Release 分支说明

发布分支：`codex/release`。

清理前的完整源码保存在 `codex/song-import-rhythm-research` 分支及提交 `871bef0`，需要恢复测试或查看研究过程时可从该提交读取。

## 本分支清理范围

- 移除 `Assets/Tests` 的 PlayMode 测试与测试程序集。
- 移除各系统的独立回归验证脚本、测试运行器、删除操作验证会话。
- 移除已完成的美术接入／截图工具和整曲关卡一次性生成工具，保留已经生成的预制体、谱面和美术资产。
- 移除 `Research` 下的音频实验、交互探针、测试构建脚本及其结果副本。
- 从战斗场景中移除旧 HUD 调试数据源，并清理编辑器中的相应创建与调用代码。
- 清理 `SampleScene` 相机上引用已丢失 Timeline 资源的旧演示组件。
- 移除接入工具中的截图对比、独立回归测试入口，保留配置合法性检查。

## 保留内容

- 游戏运行代码、曲目目录、弹幕谱面、Spine 角色和所有 UI／按钮素材。
- 弹幕与玩家动作编辑器、音乐解析、素材导入、场景接入工具。
- `ImportedButtonTheme` 和 `ImportedButtonArtwork`：实际运行时生成页面及克隆按钮仍需要这些组件。
- 当前仍有资产／工具引用的运行组件和既有包依赖；本次不按名称包含 Debug 或 Test 就盲目删除依赖。

## 构建

使用项目指定的 Unity `2022.3.62f1c1`，从 Build Settings 中启用的场景构建 Windows x86_64；正式版本关闭 Development Build。

本次检查产生的报告和本地构建位于被 Git 忽略的 `Logs/` 和 `Builds/Release/`，不会随发布源码提交。

## 清理后的验证记录

- 在独立临时工程中完成全新导入与源码编译。
- 检查 5 个场景、13 个预制体：无缺失脚本、无失效序列化对象引用。
- Windows x86_64 正式构建成功，`BuildOptions.None`，构建报告为 0 个错误、0 个警告。

历史设计文档保留作为背景，其中提及的旧测试菜单以本说明中的清理范围为准。
