# 聚光灯：系统实现与使用说明

2026-10-06。首版 PC / 键盘鼠标 / 可替换占位美术。范围以本次确认记录为准。

## 开始运行

1. 在 Unity 2022.3.62f1c1 打开 `Assets/Scenes/Title.unity`，进入 Play。
2. 主菜单设置可编辑画质、声音和键位。首次没有有效进度时“继续游戏”禁用。
3. 开始游戏经过至少 1 秒的加载页，进入 `GameplayPlaceholder`，显示 HUD 和调试道具。已有有效进度时，开始新游戏先弹出覆盖确认。
4. 按住 Tab 展开道具栏；数字键 1～9、0 或鼠标点击选择。松开 Tab 关闭并保留选择；R 单独使用。数量为零的道具退出选择栏。
5. Q / E 分别请求技能 1 / 2。当前占位业务在 HUD 显示请求提示；这不是正式技能效果。
6. Esc / 右上角按钮打开暂停。设置取消返回暂停；继续游戏才恢复已注册的运行目标。
7. 暂停中保存“局外养成 + 关卡入口”。继续游戏从入口重建关卡，局内血量、道具消耗等不会保存。

前三个场景已加入 Build Settings，Title 为第一入口，原 SampleScene 保留。

布局依据 PDF 的原型图：主菜单按钮底部横排；设置顶部三页签、左标签右控件、右下角操作；HUD 左上头像/血量/道具、左下竖向体力及技能/麦克风、横向选择栏、右上暂停；暂停居中竖排；加载中心角色占位与提示、右下进度。占位加载角色使用轻量摆动动画，正式跑步动画可替换。

Canvas 采用 1920×1080 参考尺寸和项目已有 SafeArea。设置内容可滚动，较低分辨率依靠 Canvas 缩放保持布局。真实窗口分辨率在 PC Player 中应用；Unity Editor 中保持 Game View。

## 设置行为

设置界面使用独立 `SettingsEditSession`：

- 打开：复制已应用数据和运行输入资产，并显式恢复已生效的键位覆盖值，再编辑副本。Unity 的 Instantiate 不会复制 InputBinding 的非序列化覆盖字段。
- 音量滑条：立即试听；取消恢复已应用音量。
- 应用：校验显示选项和键位，应用运行时设置，写盘成功后更新基线。写盘失败恢复上次有效值。
- 重置：只把本次草稿改为默认，仍需应用才保存。
- 应用成功后继续编辑、再取消：保留上一次应用结果。

分辨率候选严格为 512×288、768×432、1024×576、1280×720、1334×750、1366×768、1536×864、1600×900、1920×1080、2048×1152、2560×1440。首启优先选择列表中适合桌面的最大尺寸；桌面原生尺寸不在列表中时，不额外增加候选。

FPS 为 1、5、10、20、30、60、120、无限制，默认 60。只设置 VSync 和渲染上限。弹幕与玩家的固定模拟步长仍为 1/60 秒；播放器改用未截断的帧间时间乘 timeScale，防止 1 FPS 时因 Unity maximumDeltaTime 截断而减速。每次渲染更新可执行多个固定 Tick；原有补跑预算与暂停清理累积的行为保留。

显示模式支持窗口、独占全屏、无框全屏；独占全屏依据 Screen.resolutions 禁用不支持的尺寸，无框全屏跟随桌面尺寸，并保留用户选中的尺寸供后续切换窗口模式使用。

声音有总音量、背景音乐、音效、音量比例四项。前三项 UI 取值 0～100，应用到音源时为：基础音量 × 总音量比例 × 通道音量比例。第四项 UI 0～100 对应 `VolumeScale` 0～1，通过 `AudioVolumeService.VolumeScale` / `ScaleChanged` 给后续模块读取；当前不会重复乘到前三项音量。音频设备控件显示跟随系统，首版无设备枚举、切换或麦克风授权操作。

给真实音源添加 `SpotlightAudioSource`，选择 Music 或 Effects；也可直接 Register/Unregister。注销会恢复基础音量，避免再次启用时重复缩放。

## 输入与业务接入

| 动作 | 默认绑定 |
| --- | --- |
| 左 / 右移动 | A / D |
| 跳跃 / 长按飞行 | Space，共享 JumpFly 动作；两行改键联动 |
| 闪避 | Left Shift |
| 技能 1 / 2 | Q / E |
| 道具选择 / 使用 | Tab / R |
| 暂停 | Esc，固定 |

业务动作支持键盘重绑定。普通动作之间拒绝冲突，数字键保留给道具槽，Esc 保留给界面。等待新键时 Esc 只取消等待，下一次 Esc 才关闭设置。应用后同步 HUD 提示。当前 JumpFly 的按下、松开、保持时间提供给业务层，UI 不定义飞行启动阈值。

真实 HUD 数据源实现 `IHudDataSource`，通过 `Current` 和 `Changed` 提供 `HudSnapshot`；业务请求实现 `IGameplayRequestSink`，分别处理选道具、用道具和技能。关卡对象在准备完毕后调用：

```csharp
SystemRoot.Instance.AttachGameplay(hudDataSource, requestSink, progressProvider);
```

销毁时调用 `DetachGameplay(hudDataSource)`。HUD 按稳定 ItemId 对应图标与数量，真实库存只有业务层能修改。初版最多显示 10 个选择槽；超过时会显示配置提示。占位源 `HudDebugDataSource` 的扣数量、提示技能请求、养成数值只用于演示接口。

`GameplayCommandBuffer` 保存按下/松开/闪避/技能/使用等一次性命令，并提供 Horizontal、JumpFlyHeld、HeldSeconds。默认占位场景每帧消费一次；正式固定步运行器接入时先设 `SystemRoot.ExternalCommandConsumer = true`，然后在权威 Tick 边界调用 `ConsumeGameplayCommands()`，并用 `CommandConsumed` 处理运动命令。技能/道具请求会在同一次消费中分发到已绑定的 sink，业务不要再次重复调用。

新增输入资产没有自动替换既有 `PlayerInputSampler` 的上下移动/射击等旧弹幕输入。真实关卡需要按上述契约接入并停用重叠的旧系统快捷键。

## 暂停与保存

实际运行目标实现 `IPauseTarget`，注册到 `SystemRoot.Pause`。现有 `DanmakuSequencePlayer` 可直接添加 `DanmakuPauseAdapter`。服务以可释放句柄计数，只在首个句柄暂停，在最后一个句柄释放时恢复原本处于播放状态的目标。原先已停止的目标不会被错误启动。

局外数据实现 `IProgressDataProvider`：Export 导出 Id/Value 列表，Restore 还原，ResetNewGame 重置新游戏。入口表必须有对应 Id，场景必须加入 Build Settings。确认开始新游戏后清理旧进度，在目标数据源接入时重置本局，但不自动生成存档；继续在接入时恢复已保存的养成。取消新游戏确认会保留原存档。

游戏内暂停菜单的“退出游戏”调用 `SystemRoot.AbandonGame()`，放弃本局、清理 `progress.json` 及其 `.tmp` / `.bak` 文件，并返回标题。返回后“继续游戏”置灰，重新启动也不能恢复这局；已有的个人音量、显示和键位设置保留。本局即使曾点击保存，选择“退出游戏”也会丢弃该局存档。显式保存仍可供正常继续流程读取，退出本局不会调用保存。标题菜单的“退出游戏”仍关闭程序（Editor 中停止 Play）。

设置写入 `Application.persistentDataPath/Spotlight/settings.json`，进度写入同目录 `progress.json`。采用临时文件 + 原子替换并保留备份，不写项目 Assets。无档、损坏档、未知版本分开识别。测试使用独立随机子目录，不覆盖个人保存数据。

## 编辑器工具与验证

- `Tools/Spotlight/搭建系统UI与占位场景`：通过 Unity Editor API 创建占位资源、Prefab、引用和场景。已有资源可重复生成；此操作会重新生成 UI 布局，应先保留手工调整。交付的资产已经生成，无需首次运行前再执行。
- `Tools/Spotlight/从CSV导入加载文案`：读取 Id,Text,Weight,Enabled 四列，支持带逗号、引号和换行的引号字段。
- `Tools/Spotlight/运行系统验证`：设置事务、绑定、保存失败回退、局外存档、暂停、输入消费、渲染档位时钟、CSV、Prefab 和入口检查，结果在 `Logs/SpotlightValidation.txt`。写盘失败用例会故意制造并捕获一次 IO 异常。
- Test Runner / PlayMode / `Spotlight.Tests.SystemFlowTests`：真实场景、UI 输入、键位捕获、滑条鼠标点击、Tab 保持/释放、R 消费一次、道具归零、暂停返回、继续恢复和长渲染帧模拟。改键回归还覆盖重新打开设置、应用其他选项、销毁后重建 SystemRoot 从磁盘恢复，以及取消重置/应用重置。放弃本局回归覆盖返回标题、继续置灰、重新启动后仍无存档、清理备份、保留个人设置，以及重新开始重置养成。批处理测试临时调整输入焦点设置，结束后还原。

`Logs/SpotlightPlayMode.xml` 记录 PlayMode 结果，`Logs/SpotlightScreenshots/` 是 Unity 对实际运行 UI 的原生相机渲染。`Logs/SpotlightPCBuild.txt` 记录 Windows 64 位构建结果，构建目录为 `Builds/SpotlightPC`。

本版交付的正式边界：系统 UI、设置、保存、场景流程、输入绑定、HUD 数据与交互接口已经落地；正式关卡、美术、技能/道具效果、飞行/闪避运动、伤害、弹反、设备能力和麦克风授权由后续业务接入。
