# 预设片段上的发射／分裂关键帧：简短设计方案

状态：已按确认方案实现；以用户截图中的片段条和右键操作为准。验证记录见 Logs/DanmakuValidation.txt 和 Logs/DanmakuKeyframeVerification.txt。

## 编辑方式

保留当前八种预设及各自的片段条，例如“环形扩散”“自机狙”“子母弹”。一个片段仍使用一种预设，共用形状、数量、速度、发射器和子弹参数；关键帧主要决定触发时间。

- 在片段条内右键，选择“添加发射点”，在鼠标对应的位置生成发射标记。到达该点时，按该片段预设发射一次完整弹幕。
- 标记直接画在原片段条上，不新增发射／分裂子轨。发射点和分裂点使用不同颜色与图标。
- 左键选中标记，在 Inspector 输入精确时间；拖动标记改变时间；右键标记可复制或删除。子母弹受单次限制，不能复制出第二个发射点或分裂点。点击片段空白区域仍选择片段，拖动片段整体移动。
- 支持沿用音乐候选点吸附。时间保存为片段内的局部 Tick（60 Tick/秒），全局时间为片段开始时间加局部时间。

例如“环形扩散”片段从歌曲第 2 秒开始，片段内添加 0.2 秒、0.8 秒、1.4 秒三个发射点，则在歌曲第 2.2、2.8、3.4 秒各发射一整圈。片段长度本身不产生发射。

新建片段默认没有发射点，由用户右键添加。其他预设需要连续发射时，提供“按间隔生成发射点”工具；生成后都是可单独编辑的普通标记，运行时不再隐式循环发射。子母弹不提供批量生成发射点。

## 各预设的触发含义

| 当前预设 | 每个发射点执行的动作 |
| --- | --- |
| 定向单发／连射 | 发射一轮定向弹；连射由多个发射点组成 |
| 自机狙扇形 | 在该点读取玩家当前位置，同时发出配置数量的子弹，方向以玩家为中心呈扇形展开 |
| 固定扇形 | 同时发出配置数量的子弹，方向以配置方向为中心呈扇形展开 |
| 环形／多层环 | 发射一整圈或配置的多层环 |
| 旋转扫射／螺旋 | 根据该点的片段局部时间计算旋转角，发射一轮 |
| 线阵／墙弹 | 沿配置的线段发射一排弹 |
| 花瓣／交错环 | 发射一轮花瓣弹，交错相位按实际发射轮次切换 |
| 子母弹 | 一个发射点触发一次母弹发射，一个分裂点提供一次分裂机会 |

“发射一轮”表示一次发射动作，不表示单颗子弹，也不表示在一段时间内连续发射。例如固定扇形配置数量 5、中心朝下、展开角 60°，到达一个发射点时同时发出 5 颗弹，方向相对中心为 -30°、-15°、0°、15°、30°。

## 子母弹分裂：已确认单次规则

每个子母弹片段最多一个发射点、一个分裂点。发射次数与子弹数量分别配置：唯一发射点执行一次发射动作，产生配置数量的母弹；唯一分裂点只触发一次，作用于该片段仍存活的母弹。无需选择目标发射点或维护批次引用。

在片段条上右键添加对应标记。已有该类标记时禁止新增第二个，仍可移动、编辑或删除现有标记。分裂点必须晚于发射点；存在分裂点但缺少发射点、时序错误或标记重复时，显示错误并阻止播放。

例如片段内 0.2 秒发射母弹、1.0 秒分裂。分裂数量、速度和子弹模板使用片段的分裂配置。母弹在当前位置被子弹替换；已经命中、越界、过期或清除的母弹不再分裂。即使母弹已经全部消失，也不会重试或再次触发。分裂产生的子弹不再继续分裂。

## 数据与运行职责

- `DanmakuClip` 增加关键帧列表，记录 ID、局部时间和类型；子母弹校验唯一发射点与唯一分裂点。预设和共用参数仍归片段管理。
- `EmissionPreset` 保留当前用途；保存预设时可保存关键帧模板，拖入时深拷贝并重建 ID。无需新增另一套片段预设类型。
- `BossSequenceRunner` 按关键帧时间调度。去掉固定间隔自动发射和母弹年龄自动分裂；同一 Tick 先处理清弹，再发射，再分裂，标记同类时保持稳定顺序。
- `ProjectileWorld` 按片段实例及母弹标识筛选分裂对象，执行一次分裂、回收及容量检查。发射／分裂在运动前执行，子弹参与当前 Tick 的推进与碰撞。
- 移动片段时关键帧一起移动；调整长度不缩放关键帧时间，越界标记保留并报错。复制片段重建内部 ID。Seek 重置后重放，结果应与连续播放一致。
- 角色输入绑定、按住射击的武器频率、战斗管理器碰撞结算及音频解析继续使用现有入口。本次改造范围是时间轴上的预设弹幕调度。
