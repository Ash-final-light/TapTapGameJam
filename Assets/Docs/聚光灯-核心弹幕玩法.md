# 聚光灯\-核心弹幕玩法

# **弹幕 Projectile 系统设计**

## **1\. 目标**

- 美术负责特效、模型等表现资源

- 程序负责 Projectile、HitBox、生命周期、轨迹、碰撞、伤害、Buff

等通用能力

- 策划通过 Prefab \+ 配置表组合弹幕

- 新增常规弹幕时，尽量不新增专用代码

**\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-**

- **需要编辑器来预览效果？**

## **2\. Projectile Prefab**

每个子弹使用统一 Projectile Prefab 结构：

```Plain Text
Projectile
├── Visual / VFX
├── HitBox
├── Movement
├── Lifetime
├── Collision
├── Gameplay Config
└── Death Behavior
```

## **3\. HitBox**

- 检测角色、场景或其他目标碰撞

- 产生 Hit Event

- 碰撞后的具体行为交给 Projectile 处理，例如转发给伤害中心

## **4\. 生命周期**

生命周期使用策略化设计。

```C#
public enum ProjectileLifetimeType
{
    HitCount,
    Duration
}
```

### **HitCount**

限制有效碰撞次数：

```Plain Text
RemainingHitCount = 3

Hit → 2
Hit → 1
Hit → 0 → Death
```

### **Duration**

```Plain Text
Duration = 5s

Spawn → 5s → Death
```

### **扩展**

并允许多个死亡条件同时存在，任一满足即可销毁。

## **5\.轨迹系统**

轨迹逻辑独立于 Projectile：

```Plain Text
IProjectileMovement
├── StraightMovement
├── WaveMovement
├── HomingMovement
└── CustomMovement
```

不同轨迹维护自己的参数。

Projectile 只负责驱动 Movement，不关心具体轨迹算法。

## **6\.** **碰撞流程**

```Plain Text
HitBox
  ↓
Projectile.OnHit()
  ↓
Gameplay Effect
  ├── Damage
  └── Buff
  ↓
Lifetime
  ↓
判断是否死亡
```

## **7\. Damage 与 Buff**

伤害和 Buff 不直接写死在 Prefab 中，通过配置 ID 查询表格。

例如：

```Plain Text
ProjectileConfigId = 10001
DamageConfigId = 20001
TargetBuffIds = [30001, 30002]
SelfBuffIds = [30003]
```

命中流程：

```Plain Text
Projectile Hit
    ↓
Damage System
    ↓
Buff System
```

Buff 系统提供通用逻辑，弹幕只配置 Buff ID。

## **8\. 死亡行为**

Projectile 统一进入：

```Plain Text
Projectile.Die()
```

死亡流程：

```Plain Text
Death
  ├── 播放 Death VFX
  ├── 生成后继 Projectile
  └── 回收当前 Projectile
```

### **Death Transition**

通过实现interface来定义每个子弹死亡后的行为

支持子弹死亡后生成新的 Projectile：

- 分裂弹

- 爆炸弹

- 子母弹

- 多阶段弹幕
