## 2. 系统 PDF 中已明确的需求

### 主菜单

- 背景与游戏 Logo 展示；背景不遮挡按钮，Logo 在支持的分辨率下保持清晰。
- 开始游戏：经过加载界面进入新手关卡；已有进度时先二次确认重置，无存档时不确认。
- 继续游戏：存在有效存档才可点击。用户已选择 A：保存局外养成及关卡入口，继续从关卡起点进入，不恢复退出前的局内模拟状态；此决定覆盖 PDF 主菜单中“恢复局内自动存档”的原要求。
- 设置：关闭设置后保留主菜单状态。
- 退出：关闭游戏；编辑器调试改为停止播放。
- 损坏或版本不匹配的存档按无存档处理，不崩溃，给出一次提示。
- 主菜单停留期间不允许后台加载关卡。

### 加载界面

- 黑或白背景、主角原地跑动循环动画、简短配置文案。
- 文案配置字段建议包含文本 ID、显示文本、权重、是否启用；新增文案不改代码。
- 加载时长目标 3 秒以内；超过 3 秒必须有进度反馈；不足 1 秒时仍至少展示 1 秒。
- 加载完成自动进入目标场景，不增加继续按钮。
- 加载超时或缺少资源时给出可读错误和重试按钮。
- 3 秒是设计目标，需通过目标设备测量，不能作为已达到的性能结论。

### 设置

- 三页签：画质、声音、操作键位；选中页签有颜色及加粗边框。
- 分辨率候选：512×288、768×432、1024×576、1280×720、1334×750、1366×768、1536×864、1600×900、1920×1080、2048×1152、2560×1440。
- 已根据 PDF 第 5 页原图及用户第二张附件更正为 `1366×768`。实际不支持的组合置灰。
- 分辨率默认跟随显示器推荐值；切换时关闭已有全屏弹窗，具体返回流程需要在草案中定义。
- 帧率候选：1、5、10、20、30、60、120、无限制；默认 60。用户已确认只限制渲染帧率，不改变现有 60 Hz 逻辑。
- 显示模式：窗口、全屏、无框窗口；开发期默认窗口，正式版默认全屏。
- 音量为 0～100 整数。滑动即时生效；仅点击应用才保存，取消需恢复已保存值。
- 音量页保留总音量、背景音乐、音效，并按用户要求增加第四项，后续作为音量比例 scale；第四项显示名和目标通道尚待确认。
- 用户已选择设备 B：保留音频输入/输出 UI 与状态接口，首版显示跟随系统，不实现实际设备切换、设备枚举或权限获取。麦克风 UI 接收外部状态。
- 点击键位进入修改状态，按下新键完成一次修改并退出；冲突需检测提示，不允许同一功能绑定两个键，不允许重绑定 Esc。
- “官方推荐操作键位”仅静态展示，不能修改。
- 重置只将未保存草稿恢复为默认值；应用保存并生效；取消、Esc 等关闭操作丢弃未保存草稿；只有应用写盘。
- 用户已确认第一张附件中的动作：左移动 A、右移动 D、跳跃 Space、飞行（长按）Space、闪避 Shift；另加技能 1=Q、技能 2=E、道具选择栏=Tab、道具使用栏=R，并支持后续改键。暂停仍按 PDF 固定 Esc。

### HUD 与暂停

- 角色头像；默认 5 点血，每次有效受击扣 1 点，技能可提升上限。
- 血量从左向右增加、从右向左减少；美术提供满格、空格和掉血过渡帧。
- 道具图标与数量、当前装备展示。
- 体力默认上限 100，冲刺单次消耗 25，技能可提高上限，恢复时间支持配置；低于 30% 建议警示色。
- 两个技能图标对应 Boss 两种弹幕颜色，颜色必须一致；弹反的实际规则尚未提供。
- 长按道具选择键打开小弹窗，用主键盘数字键选择；数量为 0 的道具不显示，选中项显示边框。道具选择栏和使用栏有各自键位；选择后更新使用栏，使用输入发布业务请求，实际道具效果由外部业务层负责。
- 麦克风开启常亮、关闭置灰；未授权时也要有明确状态，实际用途待第三章。
- 状态类信息放屏幕边角，Boss 预警及弹幕颜色提示靠近角色或战斗区域。
- 点击右上角暂停或按 Esc 暂停；暂停页提供继续、保存进度、设置和退出。
- 暂停页明确：手动保存仅保存局外角色养成，退出后局内进度重置。
- 从暂停页进入设置后关闭设置，应该仍保持暂停；最终窗口返回规则在草案中细化。

## 3. 现有实现基线

| 能力 | 当前证据与边界 |
| --- | --- |
| 弹幕资产与编辑器 | `DanmakuSequence`、`EmissionPreset`、`ProjectileDefinition` 及自定义编辑器已存在；八类基础组合、局部覆盖、重演预览已有实现 |
| 弹幕运行时 | 固定 60 Hz、FP64 逻辑、目标专用宽相位、批量 Sprite 绘制；普通子弹不逐颗创建 GameObject |

| 玩家 | 定点普通/低速移动、摇杆强度、场地边界、动态判定半径；玩家与弹幕共用播放器时钟 |
| 伤害接点 | `DanmakuSequencePlayer.OnProjectileHit` 带子弹 ID、Tick、位置、DamageConfigId、TargetBuffIds；未发现完整 Damage/Buff 服务 |
| 暂停接点 | 播放器已有 Pause/Resume，清理时间累积及一次性输入；尚未自动消费 PausePressed 打开界面 |
| 战斗后续 | 未发现血量、体力、冲刺、道具、双颜色弹反的完整业务模块；不能将输入动作或事件接点当成已实现玩法 |
| 屏幕适配 | 已有 SafeArea、CanvasWidthAdjuster 与独立运行时程序集，可复用 |
| 窗口系统 | Windowing 中查到的是受条件编译控制的编辑器调试窗口，未发现对应完整运行时窗口服务 |
| 主菜单 | `Assets/Scenes/Title.unity` 目前只有 Main Camera，未发现菜单 Canvas 和交互 |
| 构建场景 | 当前 EditorBuildSettings 仅启用 SampleScene；Title 尚未加入 |
| 系统目录 | `Assets/Scripts/System` 未发现实际系统源码；未发现存档、设置或 AudioMixer 资产 |

命中时序须在正式草案中明确：模拟先收集本 Tick 命中、扣除子弹 RemainingHits 并处理死亡，随后集中发布 OnHit。仅在第一个回调中关闭玩家碰撞，不能撤销本 Tick 已收集的其他命中。受击保护必须在战斗层拒绝重复伤害；若需要“无敌时不消耗子弹命中次数”等规则，还需在模拟内部增加命中决策接点。

`OnInputTick` 当前在玩家移动与弹幕模拟之后发布。暂停 UI 可以消费这一事件，但冲刺、弹反等需要影响当前 Tick 判定的动作不能简单地都挂在这个事后事件中；后续战斗草案应明确前置处理顺序。

- 关卡实际名称、首次进入内容、关卡入口/解锁规则以及自动存档触发点尚未给定。
- 实际扣血、闪避运动、飞行运动、体力恢复、弹反成功效果、道具效果由外部业务提供。本轮完成所需状态字段、事件与调试数据，不自行定义这些玩法。

- 手机设置项目与触控布局需要平台适配；已有手机虚拟控件接入说明，但场景控件尚未创建。
- 高级运动、擦弹、激光、相对连续碰撞检测、快照缓存均不能视为已完成；按选定范围安排。
- 历史性能报告不是本轮复测结果；目标手机、峰值弹量、URP 完整场景及 Player 构建仍需验收。

## 10. 本轮键位清单

| 动作 | 默认键 | 交互/状态 |
| --- | --- | --- |
| 左移动 | A | 以用户第一张附件为准 |
| 右移动 | D | 以用户第一张附件为准 |
| 跳跃 | Space | 与飞行共享默认键，按下/长按的识别由业务层确定 |
| 飞行（长按） | Space | 与跳跃共享默认键；重绑定是否联动待确认，不视为普通冲突 |
| 闪避 | Shift | 按用户图片名称，不沿用旧输入中的 Focus 命名 |
| 技能 1 | Q | 支持改键，绑定设置及业务请求接口 |
| 技能 2 | E | 支持改键，绑定设置及业务请求接口 |
| 道具选择栏 | Tab | 支持改键，按住显示、松开关闭，用主键盘数字键选择 |
| 道具使用栏 | R | 支持改键，发出当前道具的使用请求，业务返回状态刷新数量 |
| 暂停 | Esc | 固定系统操作，不允许重绑定 |

旧弹幕输入中的上下移动、低速移动、射击、Bomb 不加入本轮设置动作清单；现有输入兼容与业务接口的迁移会在正式草案中说明，需求确认阶段不修改输入资产。
