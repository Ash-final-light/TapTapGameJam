# 战斗第二阶段：能量球与连击

日期：2026-10-07。状态：核心代码与可配置接口已落地并通过 Unity 2022.3.62f1c1 引擎验证，实战参数及同 Tick 规则等待用户确认；未将验证夹具的数值写入 GameplayPlaceholder。

本次仅涉及可击碎母球、膨胀、爆炸环和单纯累计连击。沿用现有 ProjectileWorld、BattleSimulation、CombatResolver、输入和音乐时钟。普通敌弹不加入玩家弹交互；子球不可再次击碎或分裂。

## 已实现的接口

- `ProjectileSettings.Interaction`：`Ordinary` 或 `EnergyOrb`。只有敌方子母弹片段的深度 0 母球可成为能量球。
- 能量球生命固定为 1。玩家弹按现有伤害配置减去母球生命，成功击碎时增加一次连击；若使用小于 1 的测试伤害，需要累计足够伤害才击碎。
- 初始视觉尺寸与判定半径继续使用 `VisualSize`、`HitRadius`；终值使用 `EnergyOrb.FinalVisualSize`、`FinalHitRadius`，曲线支持 `Linear`、`SmoothStep`。二者分别配置，终值不得小于初始值。
- `EnergyOrb.ContactDamage`：是否沿用原有敌弹对玩家的接触伤害和无敌耗弹策略。发生有效角色命中或按无敌耗弹策略消耗后母球立即回收，即使模板 `HitCount > 1` 也不能再爆炸。关闭时母球不伤害玩家，爆炸子弹仍按普通敌弹处理。
- `Emission.SpawnPosition`：`Emitter` 保留当前发射位置策略；`RandomArea` 在 `RandomSpawnMin` 到 `RandomSpawnMax` 的矩形内逐颗采样。这是战斗局部坐标中的绝对出生位置，覆盖形状的位置偏移，而非随机偏角。
- `Emission.PlayerProtectionDistance`：随机出生点与当 Tick 玩家位置的中心距离。保护半径不是玩家与母球半径之和。固定随机流按片段稳定 ID 独立，最多尝试 32 次；无法满足距离时报告 Fault 并停止后续生成，不偷偷出生到安全区内。

这些是可配置能力，不代表已经确认最终出生区域、保护距离、接触伤害或膨胀参数。现有实战资产仍使用原配置。

## 当前时序与生命周期

当前保持基线顺序：玩家移动 → 清弹及发射／分裂关键帧 → 武器射击 → 弹幕推进与扫掠候选 → CombatResolver → 生命周期回收。

若分裂点在局部 Tick 10，必须在执行该关键帧前已击碎母球；同一个执行 Tick 内才到达的玩家弹无法阻止该次爆炸。若用户选择同 Tick 击碎优先，必须修改爆炸提交与子弹出生／推进顺序，并重新验证 Seek；当前代码不宣称支持该语义。

膨胀按出生 Tick 到分裂 Tick 计算，在前一 Tick 推进到分裂边界时达到终值。曲线决定各 Tick 边界的半径；一个 Tick 内按两个边界半径线性变化求连续碰撞。

击碎、接触命中次数耗尽、清除、过期、越界的母球不会再爆炸。分裂只作用于指定片段存活母球；回收前先捕获值，避免子弹复用母球池对象时污染后续母球。出生时重新初始化生命、半径、增长进度与分裂时间。

## 碰撞与结算

`CombatContact` 同时保存玩家弹实体 ID、目标实体 ID、`CombatTargetKind` 与接触时间。玩家／Boss／能量球分别分流，结算器不再把非玩家目标一律解释为 Boss。

玩家弹只查询能量球空间索引。索引覆盖母球与玩家弹的整个扫掠范围；精确判定使用双方相对位移和可变半径。极大扫掠采用有界降级，只扫描可击碎母球，仍不生成全部子弹的两两候选。

接触按时间、源实体 ID、目标类型和目标 ID 稳定排序。穿透弹每个有效目标消耗一次命中次数，持续重叠不重复消耗；同 Tick 多弹遇到同一母球时，首个有效击碎标记其死亡，后续接触跳过，不再次累计，也不额外消耗后续子弹。

## 连击与表现层接入

`BattleSimulation.Combo.Count` 是该场战斗累计值，开始一场新战斗时创建新的状态。本阶段没有受伤清零、超时、倍率或奖励。

通过现有 `BattleManager.Resolved` 订阅：

```csharp
void OnResolved(BattleEvent result)
{
    if (result.Type == BattleEventType.ComboChanged)
        comboView.SetCount(result.ComboCount);
    if (result.Type == BattleEventType.EnergyOrbDestroyed)
        orbEffects.PlayAt(result.Position);
}
```

`comboView`、`orbEffects` 是接入示意，不是新建的正式 HUD。事件携带 Tick、双方实体 ID、目标类型、OwnerId、伤害配置 ID、剩余生命、位置与累计值快照；不保存池对象引用。当前阶段交付事件接口，正式 HUD 布局属于后续工作。

## 编辑器操作

退出 Play Mode 后按 `Ctrl+R`（Assets → Refresh）载入新脚本。项目没有 Pipeline 连接，且此前临时自动刷新入口已移除，因此不能用 CLI 假定当前编辑器已经载入最新代码。

1. 打开 `Tools → Danmaku → Boss 弹幕编辑器`，选择已有 Sequence 和子母弹片段。
2. 在原片段条内右键添加唯一发射点和唯一更晚的分裂点。
3. Inspector 的「单弹参数」中选择 `Interaction = EnergyOrb`，配置初始／终值视觉尺寸与判定半径、曲线、`ContactDamage`。使用共享模板时在对应 Projectile Definition 资产中修改；使用片段覆盖时勾选「本片段覆盖单弹参数」。
4. 「发射参数」中可选 `SpawnPosition = RandomArea`，明确填写矩形与保护中心距离；数量仍由 `Count` 与 `SpeedLayers` 决定。只需要静止母球时将 `Speed` 设为 0。
5. 子球模板、数量、速度继续使用 `SplitChild`、`SplitCount`、`SplitSpeed`，形成一圈弹幕。

以上具体数值需用户确认后再写入实战资产。不能把测试夹具的区域、尺寸或速度当成推荐平衡参数。
